# Entari 命令与音游图片更新

2026 年 9 月 29 日 · 适用于葱喵Bot的 Entari 后端

本站还记录了其他后端的功能。命令是否可用，以当前 Bot 的 `#help` 为准。

## 命令怎么找

- `#help` 展示横向多栏命令总览图，只列出当前启用的模块；`#help 列表` 查看模块索引。
- `#help osu`、`#help 中二`、`#help 舞萌`、`#help 咖啡` 可分别查看一个模块。
- `#` 与 `^` 都是可用的命令前缀；原有不冲突的长命令继续保留。需要复制文字时，请看 [完整命令清单](https://github.com/YoisakiKnd/entari/blob/main/COMMANDS.md)。

| 想做什么 | 现在这样发 | 补充 |
| --- | --- | --- |
| 看 osu! 玩家资料 | `#osu 我` | 已绑定可省略用户名；也可指定用户名 |
| 看 osu! 最佳 / 最近成绩 | `#bp 5` / `#re` | 最近通过用 `#pr` |
| 查 osu! 谱面 | `#osu 查 <beatmap ID 或链接>` | 无需绑定账号 |
| 查 osu! 单谱成绩 | `#osu 分 <beatmap ID 或链接>` | 需要可查询的玩家账号 |
| 看中二 B30 | `#b30` | 已绑定可省略用户名 |
| 查中二曲目 / 成绩 | `#中二 查 <歌名>` / `#中二 分 <歌名>` | 单曲成绩可追加难度色 |
| 看舞萌 B50 | `#b50` | 也可用 `#舞萌 b50` |
| 看 Steam 状态 | `#steam 我` / `#steam 群` | 个人主页 / 群友状态 |
| 看 DJMAX B100 | `#dj b100 4` | `dj` 是 `djmax` 的短写法 |

## 图片有哪些变化

osu! 玩家资料改为横版，头像、身份、PP 与排名在上方，等级、准确率和游玩数据在下方。最近成绩、单谱成绩与查图使用 osu! 自己的深色卡片；查图会附可复制的谱面链接。

中二节奏的查歌、单曲成绩与 B30／New 20 使用项目自制的 MATE 启发配色和抽象背景，未缓存曲绘时显示占位图。这套图片不复用舞萌素材或模板。

帮助图改为更宽的多栏排版；在手机上只想看一块内容时，用 `#help <模块>`。绑定、报错与操作指引仍然是文字，**不是所有回复都改成图片**。

## 找不到命令？

先用 `#help 列表` 确认模块是否已启用，再用 `#help <模块>` 查看当前写法。osu! 个人成绩需要绑定或指定用户名，但单纯查谱面不需要绑定。遇到问题时，请把输入的命令和 Bot 回复一起发给维护者，便于确认由哪个后端处理。
